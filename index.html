Descomprime este ZIP. 2. En tu repositorio de GitHub, sube index.html y la carpeta assets completa (no subas el ZIP dentro del repositorio). 3. Confirma los cambios en la rama main. 4. En Cloudflare Pages, usa el repositorio conectado. 5. Para esta página estática: Framework preset = None, Build command = dejar vacío y Build output directory = / (si Cloudflare no acepta /, usa .). 6. Guarda y despliega.
